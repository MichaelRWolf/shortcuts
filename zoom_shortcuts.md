## Meeting Controls

| Shortcut | Shortcut (Text) | Action | Notes |
| -------- | ---------------- | ------ | ----- |
| ⇧⌘A | Shift-Command-A | Audio mute/unmute | |
| ⇧⌘V | Shift-Command-V | Video show/hide | |
| ⇧⌘W | Shift-Command-W | Toggle speaker/gallery view | |
| ⌃N | Control-N | Next 25 participants | |
| ⌃P | Control-P | Previous 25 participants | |
| ⌘K | Command-K | Jump to Chat | |
| ⌃\\ | Control-Backslash | Toggle “Always Show Meeting Controls” | |
| ⌥⌃⌘H | Option-Control-Command-H | Toggle floating meeting controls | |
| ⇧⌘H | Shift-Command-H | Toggle Chat panel | |
| ⌘V | Command-V | Show Participants panel | |
